# 🎵 JBMusic

Projeto de **Desenvolvimento Web** criado para apresentar o trabalho e a identidade visual de um projeto musical, utilizando uma interface moderna, visual e interativa.

> 🚧 **Status: Em desenvolvimento**

## 📸 Preview

![JBMusic Preview](./images/preview.png)

## ✨ Funcionalidades

* Carrossel interativo com navegação por seções;
* Efeito de cursor personalizado para desktop;
* Animações durante a rolagem da página;
* Galeria de vídeos;
* Reprodução de vídeos em modal;
* Interface adaptada para diferentes tamanhos de tela;
* Navegação entre as principais seções do projeto.

## 🛠️ Tecnologias

* **HTML5** — estrutura e organização do conteúdo;
* **CSS3** — layout, responsividade, animações e efeitos visuais;
* **JavaScript** — interações, animações, Intersection Observer e reprodução dos vídeos;
* **Git/GitHub** — versionamento e gerenciamento do projeto;
* **Vercel** — publicação da aplicação.

## 💡 O que pratiquei

Durante o desenvolvimento, pratiquei conceitos importantes de Front-end, como:

* Manipulação do DOM;
* Eventos em JavaScript;
* `IntersectionObserver`;
* `requestAnimationFrame`;
* Manipulação de classes e elementos;
* Uso de atributos `data-*`;
* Criação de modais;
* Reprodução de vídeos com JavaScript;
* Responsividade com CSS;
* Organização de arquivos e assets.

## 🎯 Objetivo

O projeto foi desenvolvido como uma experiência prática de **Desenvolvimento Web**, buscando combinar estrutura, design e interatividade em uma única aplicação.

Além de praticar conceitos técnicos, o projeto representa uma etapa da minha evolução no desenvolvimento Front-end e continua sendo aprimorado conforme novos conhecimentos são adquiridos.

## 🚧 Próximos passos

Como o projeto ainda está em desenvolvimento, algumas funcionalidades e seções poderão receber melhorias, novos conteúdos e ajustes de experiência do usuário.
